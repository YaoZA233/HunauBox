# 学习通消息

入口为「功能 → 教务与学业 → 学习通消息」，也可以在首页添加快捷入口。该功能与应用里的校园通知是两个不同来源。

学习通消息页面使用环信 WebIM，历史消息由网页 SDK 解码。应用通过无界面 WebView 登录并加载学习通自己的消息网页，提取页面上已渲染的会话名称、摘要、时间以及选中会话中已加载的消息。应用不会发送消息；会话列表和成功打开过的详情按校园账号保存在本机，重新进入时先显示缓存，主动刷新成功后更新。打开页面或会话可能触发学习通原网页的自动已读行为。

详情仅包含网页当前加载的消息；更早历史、部分特殊消息与附件可通过右上角「打开学习通消息网页」查看。文件夹中的会话和列表分页是否显示取决于学习通当前网页状态。网页登录过期时可从应用打开网页登录，返回后同步 Cookie 并重试。

页面元素来自学习通 WebIM 的内部实现，网站改版可能需要更新提取规则。发现加载中或历史加载失败时等待或显示错误，不将失败当作空消息；刷新失败保留旧缓存。会话顺序、名称或摘要变化时，不复用旧详情，避免详情错配。页面打开期间刷新复用 WebView 并重新加载网站；页面退出、打开网页或加载失败时释放 WebView。

验证：`flutter test --no-pub test/chaoxing_messages_test.dart` 使用模拟服务测试解析、搜索、详情、错误恢复及大字体适配；这些测试不替代真实设备登录后的端到端验证。
